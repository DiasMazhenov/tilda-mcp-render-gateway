# Tilda MCP gateway for ChatGPT Web

Один сервер Render для нескольких подключений Tilda MCP. Работает независимо от Codex и компьютера владельца.

ChatGPT проходит OAuth Authorization Code + PKCE S256 на шлюзе. Шлюз проверяет адрес конкретного сайта и передаёт запрос в https://tilda.kz/api/mcp/ с соответствующим Bearer-токеном.

## Запуск на Render

1. Открой https://dashboard.render.com/ → New → Web Service.
2. Подключи репозиторий DiasMazhenov/tilda-mcp-render-gateway, ветка main.
3. Language: Node. Build Command: `npm install --omit=dev`. Start Command: `npm start`.
4. Выбери Free для проверки. Health Check Path: `/healthz`.
5. В Environment задай:

| Переменная | Значение |
| --- | --- |
| NODE_VERSION | 24 |
| PUBLIC_BASE_URL | HTTPS-адрес сервиса без завершающего слеша |
| OAUTH_SIGNING_SECRET | 64 hex-символа, создай через `openssl rand -hex 32` |
| ADMIN_PASSWORD | Уникальный случайный пароль от 24 символов |
| TILDA_TOKEN_COMFORTCLINIC | Токен Comfort Clinic, без префикса Bearer |

Не отправляй секреты в чат и не добавляй их в GitHub. Все секреты вводятся только в Render Environment.
Если адрес сервиса ещё неизвестен, выбери имя сервиса и уточни его выданный домен в Render. После этого исправь PUBLIC_BASE_URL и перезапусти деплой.

Можно использовать New → Blueprint: в репозитории есть render.yaml. ADMIN_PASSWORD будет сгенерирован автоматически; посмотри его в Environment. OAUTH_SIGNING_SECRET нужно задать самому в hex-формате.

После деплоя открой `https://<домен>/healthz`: должен появиться JSON с `ok: true`. Это проверка запуска, не проверка токена Tilda.

## Подключение в веб-чате ChatGPT

В форме добавления пользовательского MCP укажи:

- Название: Comfort Clinic.
- Server URL: `https://<домен>/mcp/comfortclinic`.
- Authentication: OAuth.
- Client ID и Client Secret оставь пустыми, используется динамическая регистрация публичного PKCE-клиента.

При подключении откроется страница шлюза. Введи ADMIN_PASSWORD, а не токен Tilda. После возвращения в чат добавь подключение и попроси показать проекты Tilda. Названия инструментов определяются реальным сервером, шлюз их не выдумывает.

В разных версиях ChatGPT форма находится в Apps/Приложениях с Developer mode либо в Plugins → Add custom MCP server. Доступ зависит от возможностей аккаунта.

## Несколько сайтов

| Render Environment | Server URL |
| --- | --- |
| TILDA_TOKEN_COMFORTCLINIC | `https://<домен>/mcp/comfortclinic` |
| TILDA_TOKEN_MAMAVITA | `https://<домен>/mcp/mamavita` |
| TILDA_TOKEN_MY_SITE | `https://<домен>/mcp/my-site` |

Для нового сайта добавь переменную и передеплой сервис, затем создай отдельное MCP-подключение в ChatGPT. Код менять не нужно.
Имя сайта начинается с буквы, состоит из строчных латинских букв, цифр и дефисов, до 64 символов.
Токены доступа и обновления привязаны к адресу одного сайта: использовать их для другого нельзя.
Пароль владельца общий, поэтому это персональный шлюз для одного владельца, а не система разграничения доступа между клиентами.
Доступ внутри Tilda определяется правами каждого исходного токена.

## Проверки

`npm test` запускает локальные тесты OAuth, PKCE, CSRF, запрета повторного обмена кода, обновления токенов, изоляции сайтов и выбора правильного исходного Bearer-токена. Внешний Tilda API заменяется тестовым HTTP-ответом через test-support/upstream.mjs только в дочернем тестовом процессе. Тесты не меняют настоящие сайты.

Реальное подключение ChatGPT → Render → Tilda нужно проверить после деплоя. Успешные локальные тесты этого не доказывают.

## Ограничения

- Render Free засыпает после 15 минут простоя. Запуск занимает примерно минуту, возможны таймауты OAuth/MCP. Перед подключением открой /healthz и дождись ответа. Для постоянной работы используй подходящий always-on тариф.
- Прокси фиксирован на официальном Tilda endpoint; произвольные upstream URL от клиента не принимаются.
- OAuth-коды живут 5 минут. Память использованных кодов и ограничение попыток входа сбрасываются при рестарте. Для более строгой защиты от повторного обмена между рестартами нужна постоянная БД.
- Access-токены живут час, refresh-токены 30 дней. Нет индивидуального отзыва сессии и ротации с обнаружением повторного refresh. Замена OAUTH_SIGNING_SECRET отзывает все выданные подключения и требует переподключения.
- Callback разрешён только на официальные адреса chatgpt.com и chat.openai.com. Если появится ошибка invalid_redirect_uri, сравни точный callback из ChatGPT с allowlist в src/auth.mjs, не отключай проверку домена.
- Подтверждения операций записи настраиваются в ChatGPT. OAuth scopes не ограничивают инструменты записи внутри Tilda.
- Не используй персональный прототип как публичный многопользовательский сервис без дополнительной проверки авторизации.

Документация Render: https://render.com/docs/web-services и https://render.com/docs/free.
